Privacy

Last updated October 13, 2026

Nest & Paws is a set of static web pages. It has no accounts, forms, comments, or email signup, and it does not ask you for personal information.

What gets collected

  • Hosting. The pages are hosted by GitHub Pages. GitHub receives standard request data, such as your IP address and browser type, when you load a page. See GitHub's privacy statement.
  • Fonts. Fonts load from Google Fonts, so Google receives the same standard request data. See Google's privacy policy.
  • Cookies. This site sets no cookies of its own.
  • Analytics. This site does not currently run analytics. If that changes, this page will be updated first.

Links to other sites

Links to Amazon, Pinterest, and other sites take you off this site. Their privacy policies apply there.

Children

This site is not aimed at children under 13.
