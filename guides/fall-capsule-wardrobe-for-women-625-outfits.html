A capsule works when every piece goes with every other piece. Pick one layer, one top, one bottom and one pair of shoes from the five in each row. That is 5 x 5 x 5 x 5 = 625 raw combinations. Not all 625 are great, so twelve of them are shown below, built on one shared palette: olive, chocolate, cream, indigo, oxblood and black.

We did not test these. We read each Target listing and use only what it says, so check the size chart, color options and care label on the page before you buy. Prices change, so each pick says to check the current price.

If you buy one

If you only buy four pieces, buy one from each row in the same palette, then add a belt and an accessory later. The formula does the rest.

What I skipped

  • Anything where the listing does not say what the item is made of.
  • Pieces that only work in one outfit, since a capsule needs every piece to mix.
  • Brand-name designer items, since this guide is about everyday prices.

How I picked

  • Every piece is sold by Target and the link goes to Target's own page.
  • The listing states the material, fit or cut.
  • Each pick has one limit worth knowing before you buy.
  • Specs come from the listing text. Review counts and star ratings are not used here.
